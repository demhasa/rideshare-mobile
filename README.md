# RideShare

Projekt mësimor Next.js për Ushtrimet 3: lista e udhëtimeve, detajet dhe një
kërkesë e simuluar. Të gjitha të dhënat janë fiktive; aplikacioni nuk bën
rezervime reale.

## Nisja

Instalo Node.js dhe npm, pastaj nga dosja `aplikacioni/` ekzekuto:

```bash
npm install
npm run dev
```

Hap adresën që shfaq terminali (zakonisht `http://localhost:3000`).

Raporti i ushtrimit është te [java-03.md](./java-03.md), pranë këtij README dhe
jashtë dosjes së aplikacionit.
